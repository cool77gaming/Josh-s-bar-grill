**Data sources:** Live-scraped from Google Maps using the [`gosom/google-maps-scraper`](https://github.com/gosom/google-maps-scraper) agent skill (installed via `npx skills add gosom/google-maps-scraper`, run locally via Docker against real Google Maps listings across 9 Hampton, VA service-business search queries). **Caveats:** This is a point-in-time snapshot — verify phone numbers and website status before outreach. Scraping Google Maps at any real scale can run against Google's Terms of Service; this list was pulled at modest volume for the requester's own lead-generation use, not redistributed or run at scale.
